# install-wg-server

Вот готовый файл README.md для твоего скрипта. Он понятно описывает, что делает скрипт, и дает пошаговую инструкцию по установке.

🚀 Автоматическая установка WG-Easy на Debian
Этот репозиторий содержит Bash-скрипт для быстрой и автоматической установки WG-Easy (WireGuard VPN + удобная Web-панель управления) на серверы под управлением Debian/Ubuntu.

Скрипт берет на себя всю рутину: устанавливает зависимости, настраивает Docker, безопасно хеширует пароль для веб-панели и запускает контейнер.

✨ Возможности
Автоопределение IP: Скрипт сам попытается узнать публичный IP-адрес вашего сервера (можно изменить вручную).

Установка Docker: Если Docker не установлен, скрипт автоматически добавит официальные репозитории и установит актуальную версию.

Безопасность: Пароль для Web-панели хешируется с использованием bcrypt через Python, что исключает проблемы со специальными символами при передаче в конфигурацию.

Изоляция: Сервис разворачивается в рабочей директории /opt/wg-easy/ через docker-compose.

🛠 Требования
ОС: Debian (или совместимые дистрибутивы, например Ubuntu).

Права: root (или выполнение через sudo).

Свободные порты: 51820/udp (для WireGuard) и 51821/tcp (для Web-панели).

📦 Быстрая установка
Выполните следующие шаги в терминале вашего сервера:

1. Создайте файл скрипта:

Bash
nano install-wg.sh
(Скопируйте код скрипта и вставьте его в редактор, затем сохраните файл нажав Ctrl+O, Enter и выйдите Ctrl+X)

2. Выдайте права на выполнение:

Bash
chmod +x install-wg.sh
3. Запустите установку:

Bash
./install-wg.sh
⚙️ Процесс установки
Во время работы скрипт попросит вас ввести два значения:

Публичный IP сервера: Нажмите Enter, чтобы согласиться с автоопределенным IP, или введите другой (если сервер за NAT).

Пароль для панели: Придумайте надежный пароль для доступа к управлению конфигурациями VPN.

🌐 Управление и использование
После успешной установки скрипт выведет данные для доступа.

Web-панель: http://<ВАШ_IP>:51821

Рабочая директория: /opt/wg-easy/

Конфиги клиентов: Хранятся в /opt/wg-easy/wireguard/

Как перезапустить или остановить VPN?
Перейдите в рабочую папку:

Bash
cd /opt/wg-easy
Остановить:

Bash
docker compose down
Запустить:

Bash
docker compose up -d
Посмотреть логи:

Bash
docker compose logs -f
